# Workflow Rules

1. Always create a new branch instead of committing directly to `main`. Test changes first, then merge into `main` only after my confirmation.
2. Before checking any file into git, share the details with me; only check in files after my confirmation.
3. Always keep `main` changes in sync with this Google Doc: https://docs.google.com/document/d/1HHevbz7fVpbRZqDNCtVKrrEB6SQad88yIot2TKtnvhw/edit?tab=t.0
4. During conversations, always prepare a checklist of action items before making direct code changes.
5. Double-check and review all proposals to ensure they are correct before sharing.
